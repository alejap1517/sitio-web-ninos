¿Qué es Pop it?

Pop it se traduce literalmente como "explótalo". Es un juego infantil cuyo proceso se puede comparar con reventar papel de burbujas de embalaje. Sin embargo, a diferencia del papel de burbujas, los Pop-it se pueden presionar con sus sensaciones y sonidos característicos "de forma infinita": decenas de burbujas de silicona simplemente se empujan hacia el otro lado.

Reglas del juego

Los jugadores se turnan para presionar las burbujas. Es obligatorio terminar la fila que se ha comenzado. Se pueden presionar como máximo 3 burbujas al mismo tiempo (deben estar juntas obligatoriamente, no se pueden presionar varias burbujas a la vez si no están pegadas). El objetivo es hacer que el oponente dé el último paso. ¡Quien presione la última burbuja pierde!
